# Hallel Initiatives Website

Professional responsive GitHub Pages site for Hallel Initiatives.

## Upload
Keep this structure:
- index.html
- style.css
- script.js
- logo.png
- assets/images/

Add gallery1.jpg through gallery6.jpg to assets/images.

## GitHub Pages
Repository Settings → Pages → Deploy from branch → main → / (root).

## Before launch
Replace placeholder impact figures, testimonials and partner names with verified information. Connect the volunteer/newsletter forms to a form service. Replace the donation email link with the organisation's actual donation destination when available.
